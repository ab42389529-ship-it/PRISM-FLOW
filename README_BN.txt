PRISM FLOW Android Source — v0.4.0

এই সংস্করণে আসল ভিডিও এক্সট্র্যাকশন/ডাউনলোড ইঞ্জিন যুক্ত করা হয়েছে:
• yt-dlp Android library (0.18.1) — অনেক সমর্থিত সাইটের ভিডিও URL প্রসেস করে
• FFmpeg — প্রয়োজন হলে আলাদা ভিডিও ও অডিও স্ট্রিম MP4-তে মার্জ করা এবং অডিও MP3-তে রূপান্তর করার জন্য
• UI থেকে 360p, 480p, 720p, 1080p, 1440p, 2160p বা best নির্বাচন
• শুধু MP3 অডিও ডাউনলোডের অপশন
• ডাউনলোড প্রগ্রেস/ETA UI-তে দেখানোর callback
• ফাইল Downloads/PRISM_FLOW-এ সেভ করার ব্যবস্থা

গুরুত্বপূর্ণ বাস্তব সীমাবদ্ধতা:
• yt-dlp বহু সাইট সমর্থন করলেও প্রতিটি সাইট/প্রতিটি ভিডিও নিশ্চিতভাবে কাজ করবে না। সাইটের পরিবর্তন, লগইন/কুকি, অঞ্চল-নিয়ন্ত্রণ, অ্যান্টি-বট/PO-token, DRM বা সাইটের নীতি অনুযায়ী ব্যর্থ হতে পারে।
• ব্যক্তিগত, DRM-সুরক্ষিত বা অনুমতি ছাড়া কনটেন্ট ডাউনলোডের জন্য নয়। কেবল নিজের/অনুমোদিত কনটেন্ট ডাউনলোড করুন।
• লাইব্রেরির AAR বড় (প্রায় 60–80 MB বলে প্রকল্পের ডকুমেন্টেশন জানায়), তাই APK বড় হবে।
• এই নির্দিষ্ট runtime-এ Android SDK/Gradle নেই। তাই APK build বা বাস্তব ফোনে পরীক্ষা করা সম্ভব হয়নি; এই ZIP হলো ইঞ্জিন-ইন্টিগ্রেটেড সোর্স, পরীক্ষিত APK নয়।

Build requirements:
• Android Studio + JDK 17
• Android SDK Platform 35
• Android Gradle Plugin 8.7.3 / Gradle 8.9
• ABI: arm64-v8a অথবা x86_64 (এই library build-এ অন্য ABI নেই)

Project: PRISM_FLOW
Package: com.prismflow.downloader
Version: 0.4.0
Engine: yt-dlp Android 0.18.1 + FFmpeg 0.18.1
